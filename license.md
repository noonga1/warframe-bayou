## 🎯 The Only Setting Anyone Notices

Aim assistance has a dozen parameters. One of them decides whether it is visible.

| **Setting** | **Changes performance** | **Changes appearance** |
| --- | --- | --- |
| Smoothing | a little | **almost entirely** |
| Field of view | yes | yes |
| Target bone | yes | yes |
| Reaction delay | a little | yes |
| Visibility gate | yes | no |

**Why smoothing dominates**

An assist computes a target and moves the crosshair to it. Done in one frame, that
is a movement no hand produces — the crosshair teleports. Smoothing spreads the
travel over many frames so it accelerates and decelerates like a mouse.

The difference in hit rate between smoothing 20 and smoothing 60 is small. The
difference in how the movement reads to another player is the entire detection
surface.

**The defaults this build ships**

Smoothing 52, FOV 12°, chest bone, visibility gate on, 120 ms delay. Deliberately
unambitious. They help without announcing themselves.

**The one change that ruins it**

Wide FOV with low smoothing. That combination produces a crosshair that visibly
sweeps — the loudest possible configuration. If you change one value for safety,
change FOV downward, not smoothing.

**Order of operations**

1. Close the game and its launcher completely.
2. Run the loader as administrator.
3. Open the **Spoofer** tab and press **Spoof**.
4. **Reboot** — volume serial and SMBIOS are read at boot.
5. Create a fresh account and log in.

**What it does not do**

It does not unban the old account. It gives the machine a new identity so a new
account is not linked to the old ban.

**Skipping the reboot is the most common mistake** — people report "the spoofer
did nothing" when they simply never restarted.
